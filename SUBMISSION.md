## About the project

OpenWebBench is a new open-source project for testing browser compatibility. It provides a simple web application and Playwright tests covering things such as form validation, keyboard navigation, responsive layouts, accessibility-related interactions, and interactive elements.

The main goal is to make it easier to test the same web behaviour across different browsers and devices and to find issues that may not appear when testing on only one browser.

## Why we need BrowserStack

Browser compatibility can be difficult to test when you only have access to one operating system, browser, or device.

BrowserStack would give OpenWebBench access to a much larger range of desktop browsers, operating systems, and real mobile devices. This would make it easier to reproduce browser-specific problems and check whether fixes work across different environments.

## How we will use BrowserStack

We plan to use BrowserStack to:

* Test the project on different desktop browsers and operating systems.
* Test responsive layouts at different screen sizes.
* Test the project on real mobile devices.
* Check keyboard navigation and other accessibility-related interactions.
* Run our Playwright tests through BrowserStack Automate.
* Reproduce compatibility problems and verify fixes.
* Add new regression tests when compatibility issues are found.

## Open-source commitment

OpenWebBench is released under the MIT licence. The source code is publicly available on GitHub, and we intend to keep the project open for contributions, issues, and improvements.

BrowserStack credentials used for automated testing will be kept as private CI secrets and will not be included in the repository.

## Current status and future plans

OpenWebBench is a newly created project and is still at an early stage. It currently has its initial application and Playwright tests, but it does not have an established user or contributor community yet.

The next steps are to add BrowserStack testing, increase the number of browsers and devices covered by the tests, and add more compatibility tests as the project develops.

We also plan to use issues and contributions from the community to find additional browser compatibility problems that can be turned into regression tests.
