# Contributing

Thanks for helping improve OpenWebBench.

- Open an issue before large changes so the scope can be discussed.
- Keep the app dependency-light and avoid analytics or unnecessary collection of data.
- Add or update a Playwright test for behaviour changes.
- For browser bugs, include browser/version, OS/device, viewport, steps to reproduce, expected result, and actual result.
- Run `npm test` locally when practical and report any environment limitations.
- Use clear, respectful language in issues and pull requests.
